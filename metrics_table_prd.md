# Memory Board — Key Metrics Table

| Metric | Mathematical Formula | Why it matters |
| :--- | :--- | :--- |
| ***Functional metrics*** | | |
| **VRSR (NSM)** | **Target Photo Views (≥5s) ÷ Search Sessions** | **Validates core retrieval value & habit formation** |
| Nudge engagement rate | Nudge Taps ÷ Nudge Impressions | Measures top-of-funnel discovery into guided flow |
| Clue extraction accuracy | Sessions with ≥3 Chips ÷ Total Vague Queries | Ensures AI extracts enough signal to cluster accurately |
| Album tap-through rate | Album Taps ÷ Album Impressions | Proves confidence-ranked clusters match user memory |
| Guided question CTR | Questions Answered ÷ Questions Shown | Validates user trust & tolerance in narrowing loop |
| 7-Day Return search rate | 7D Repeat Searchers ÷ Total Searchers | Signals true product stickiness, not one-time novelty |
| ***Non-functional metrics (Guardrails)*** | | |
| AI response latency (p95) | P95 (t_response - t_query) < 2.5s | Speed is trust; >3s breaks conversational flow |
| False-positive rate | Bounced Photo Taps (<2s) ÷ Total Photo Taps | Guards against inflated VRSR from random guessing |
| Session abandonment rate | Dropped Sessions ÷ Initiated Sessions | Flags friction, dead-ends, or prompt cognitive fatigue |
| Gallery browsing engagement | Timeline Minutes ÷ Active Users (DAU) | Guards against cannibalizing passive gallery exploration |
