## 2. NORTH STAR METRIC (FULL-WIDTH TOP CARD)

★ NORTH STAR METRIC
Vague Retrieval Success Rate (VRSR) = % of Memory Search sessions where user found and engaged with their target photo within that session.

Session = initiated when user taps "Try Memory Search" or enters a vague search clue.
Success = user taps target photo and stays ≥5s or performs an action (share/favorite/zoom).
Per session = each search journey measured independently; 3 searches with 1 photo found = successful retrieval session.

---

## 3. COLUMN 1: SUPPORTING METRICS

SUPPORTING METRICS

🔍 Nudge engagement rate — % who tap "Try Memory Search". Top of funnel; nothing converts if they don't enter.

🧠 Clue extraction accuracy — % of sessions with ≥3 valid clue chips. Ensures AI engine extracts rich signals from vague text.

📁 Album tap-through rate — % tapping "Jump to Album". Validates clustering relevance and cognitive mapping.

❓ Guided question completion — % of questions answered, not skipped. Signals trust and momentum in the narrowing loop.

🔄 7-Day Return search rate — % searching again within 7 days. Retention and habit formation signal.

---

## 4. COLUMN 2: GUARDRAIL METRICS

GUARDRAIL METRICS
⚠️ These must not break, even if the north star rises.

📷 Gallery browsing engagement — minutes in regular timeline browsing. Must not drop; add retrieval without cannibalizing passive exploration.

⚡ AI latency (p95) — response time to surface albums and questions. Speed is trust; must stay under 2.5s.

🚫 False-positive rate — % of "found" taps with <2s dwell time. Guards against inflated VRSR from random user guessing.

🚪 Abandonment rate — % exiting mid-flow without photo viewed. Flags friction, dead-ends, or prompt confusion.

TARGETS TO BE ACHIEVED — FIRST 3-MONTH PILOT
